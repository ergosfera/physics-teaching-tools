    Link for Jose's computer

    Open this link once on his computer. The page remembers the connection, so after that he can use a bookmark.

    Create the backend (one time, about 10 minutes)

    1. Create a new Google Sheet, for example Reading practice.
    2. Open Extensions → Apps Script, delete what's there and paste the code below.
    3. Change FAMILY_KEY to a secret word of your own.
    4. Click the gear icon (Project Settings) → Script properties → add ANTHROPIC_API_KEY with your Anthropic API key. Keeping it there instead of in the code means it never appears in the sheet or on these pages.
    5. Deploy → New deployment, type Web app, Execute as: Me, Who has access: Anyone. Authorize when Google asks.
    6. Paste the Web app URL and your key above, then Save and test.
    7. Optional: in Apps Script, Triggers → Add trigger for prepareToday, time-driven, day timer, 5–6 am. The day's texts are then ready before anyone opens the pages.

    Each day costs two Claude requests: one writes both texts, one grades his answers.
