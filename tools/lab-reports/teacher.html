Google Sheet connection

All labs send their reports to one Google Sheet. You set this up once, and every lab page on this browser uses it.

📄 Open the Google Sheet
Update your Apps Script. Your sheet runs an older version of the code. Version 2 stores reports with screenshots (for example, Falling Cone); version 3 keeps one row per student for live activities (for example, Transformations with Desmos) instead of one row per answer; version 4 works in a standalone script too and asks students' pages to try again when many reports arrive at once; version 5 lets you close a lab or activity (on its teacher page, ⚙ Setup & data → Accepting reports) so the sheet stops taking reports. To update: open your Apps Script project (from your sheet: Extensions → Apps Script), replace the code with the new code below (keep your own TEACHER_KEY), save, then Deploy → Manage deployments → ✏ Edit → Version: New version → Deploy. The Web app URL stays the same, and all your reports are kept.
How to create the Google Sheet backend (one time, about 10 minutes)
  1. Create a new Google Sheet, for example Lab reports.
  2. In the sheet, open Extensions → Apps Script. Delete what's there and paste the code below.
  3. Change TEACHER_KEY to a secret word of your own. Only someone with this word can read the reports.
  4. Save, choose the function setup in the toolbar and press ▶ Run. Authorize when Google asks. The log shows the link to the Sheet where reports are saved.
  5. Click Deploy → New deployment, choose type Web app, set Execute as: Me and Who has access: Anyone. Deploy, and authorize when Google asks.
  6. Copy the Web app URL (it ends in /exec) and paste it above with your key.
Made the project at script.google.com instead of from a Sheet? That works too: the script creates a Sheet called Ergosfera lab reports in your Google Drive and saves the reports there. After Save and test, use 📄 Open the Google Sheet above to find it.

        
If you change the code later, use Deploy → Manage deployments → Edit → New version so the URL stays the same. Every report is also a row in the sheet, so you always have a backup. On another computer, open this page and enter the same URL and key.
